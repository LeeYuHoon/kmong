# 수동 테스트용 요율표. 파일을 고친 뒤 CLI에서 r 을 입력하면 다시 읽습니다.
#
# 형식: id | 카테고리 | 시행일 | 종료일 | 요율
#   카테고리  -  이면 기본 정책, 값이 있으면 그 카테고리에만 적용 (기본 정책보다 우선)
#   종료일    -  이면 무기한. 기본 정책은 종료일을 가질 수 없음 (다음 버전의 시행일이 곧 종료일)
#   요율      구간제: from~to:요율 을 쉼표로 나열, 마지막 구간은 to 를 비움 (예: 1_000_001~:5)
#             고정율: flat:요율
#   금액에 _ 를 넣어 읽기 쉽게 쓸 수 있고, 요율은 소수(18.5)도 됩니다.
#
# 규칙 (어기면 오류 메시지가 출력됩니다)
#   - 첫 구간은 1원부터, 구간 사이에 빈틈·겹침 없이 이어져야 함
#   - 기본 정책이 최소 1개 있어야 함, 같은 카테고리에 같은 시행일 중복 금지

# id          | 카테고리 | 시행일     | 종료일 | 요율
default-v1    | -        | 2026-01-01 | -      | 1~500_000:20, 500_001~1_000_000:10, 1_000_001~:5
default-v2    | -        | 2026-10-01 | -      | 1~500_000:18, 500_001~1_000_000:10, 1_000_001~:5
FIXED_10-v1   | FIXED_10 | 2026-01-01 | -      | flat:10
